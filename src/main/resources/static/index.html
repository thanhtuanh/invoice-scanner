📄 Invoice Scanner Service – Übersicht

Java / Spring Boot Service, der PDF-Rechnungen analysiert, IBANs extrahiert und gegen eine Blacklist prüft. Ideal zur Prävention von Fehlüberweisungen und Geldwäsche-Risiken.

Funktionen

  • 📥 PDF-URL via REST-API senden
  • 🔍 Textextraktion mit Apache PDFBox
  • 🚫 Abgleich gegen Blacklist-IBANs
  • 🔁 Antwortstatus: OK, FAILED (Blacklist) oder ERROR
  • 🧪 Tests mit JUnit & MockMvc

Beispiel-PDFs

  • 🛑 Blacklist-IBAN enthalten:
    invoice.pdf
  • ✅ Sichere IBAN:
    invoice-ok.pdf

Hinweis: PDFs sollten „selectable text“ enthalten (keine reinen Scans ohne OCR).

Testaufrufe mit curl

1) PDF mit blacklisted IBAN scannen

curl -X POST https://invoice-scanner-service.onrender.com/scan \
  -H "Content-Type: application/json" \
  -d '{"pdfUrl": "https://github.com/thanhtuanh/invoice-scanner/raw/main/invoice.pdf"}'

2) PDF mit sicherer IBAN scannen

curl -X POST https://invoice-scanner-service.onrender.com/scan \
  -H "Content-Type: application/json" \
  -d '{"pdfUrl": "https://github.com/thanhtuanh/invoice-scanner/raw/main/invoice-ok.pdf"}'

3) Fehlerfall: Nicht existierende URL

curl -X POST https://invoice-scanner-service.onrender.com/scan \
  -H "Content-Type: application/json" \
  -d '{"pdfUrl": "https://example.com/does-not-exist.pdf"}'

4) Fehlerfall: Leere URL

curl -X POST https://invoice-scanner-service.onrender.com/scan \
  -H "Content-Type: application/json" \
  -d '{"pdfUrl": ""}'

Regex für IBAN-Erkennung: [A-Z]{2}[0-9]{2}[A-Z0-9]{11,30}
